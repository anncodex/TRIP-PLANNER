TRIP PLANNER

Problem Statement-

Planning a trip can sometimes be confusing because there are many places to choose from and different things like budget, season and type of place have to be considered.
The Trip Planner is made to make this process simpler. It allows a user to enter their budget, select a season and choose the type of place they want to visit. The program then checks the available destinations and shows the places that match their choices.

Scope of the Project-

The project focuses on basic trip planning using Python.
The program can:
* Show available destinations
* Filter destinations according to budget, season and place type
* Search for a particular destination
* Show activities available at different places
* Calculate an estimated cost for a selected number of days
* Compare two destinations
The project currently uses destination information stored directly in the Python program. It does not include online booking, live prices or real-time travel information.

Target Users-

The project is mainly intended for people who want a simple way to get travel suggestions based on their budget and preferences.
It can also be used by beginners who want to understand how basic Python concepts can be used to make a small practical project.

High-Level Features-

1. **Destination List**
   Shows the destinations available in the program along with their type, budget and suggested duration.

2. **Trip Finder**
   Finds destinations according to the user's budget, selected season and preferred type of place.

3. **Destination Search**
   Allows the user to search for a destination by entering its name.

4. **Activity List**
   Shows the different activities available at the stored destinations.

5. **Trip Planning**
   Allows the user to select a destination and number of days and gives an estimated trip cost.

6. **Destination Comparison**
   Allows the user to compare two destinations based on their budget, duration, type and common activities.
