TRIP PLANNER

About the Project
- Planner is a simple Python program that helps users choose a travel destination based on their budget, season and the type of place they want to visit.
- The program has some different destinations stored in it. The user can check the available destinations, search for a place, find a trip according to their choices, plan a trip and compare two destinations.
- I made this project to practice the Python concepts learned in the course and use them in a small real-life type project.

Features:-
-> View available destinations
-> Find destinations according to budget, season and place type
-> Search for a destination by name
-> View different activities available at the destinations
-> Plan a trip by selecting a destination and number of days
-> Get an estimated trip cost
-> Compare two destinations
-> Basic input checking for wrong values

How to Run-
1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code or another Python editor.
4. Open the Python file.
5. Run the program.
6. Select an option from the menu and follow the instructions.

How to Use-
After starting the program, a menu is shown.
The user can select:
1. View destinations
2. Find a trip
3. Search destination
4. See activities
5. Plan a trip
6. Compare destinations
7. Exit
For example, while finding a trip, the user enters their budget, chooses a season and then chooses the type of place they want to visit. The program checks the stored destinations and shows the ones matching the choices.

Project Scope-
This is a basic trip planning program made for learning and demonstration purposes. The destinations and their details are already stored in the program, so it does not use live travel prices or online booking services.
